Home Credit Default Risk Analysis

1. Project Overview

This project analyzes the Home Credit Default Risk dataset to understand patterns associated with loan repayment difficulties and identify applicant risk segments.

2. Tools and Technologies

- Python
- Pandas
- SQLite
- SQL
- Power BI

3. Dataset

The project uses the Home Credit Default Risk dataset, including application and credit bureau information.

- Application training records: 307,511
- Target variable: "TARGET"
- "TARGET = 1": repayment difficulties
- "TARGET = 0": no recorded repayment difficulties

4. Analysis Performed

- Overall default rate analysis
- Risk analysis by income group
- Risk analysis by income type
- Risk analysis by education level
- Statistical association testing
- Credit bureau history analysis

5. Dashboard

The Power BI dashboard is saved as "powerbi/Home_Credit_Risk_Dashboard.pbix".

It visualizes default rates and applicant counts across credit history groups.

6. Key Finding

In the training dataset, 24,825 of 307,511 applicants have "TARGET = 1", approximately 8.07%.

Other findings should be added from the actual analysis results.

7. Conclusion

This project demonstrates data cleaning, exploratory data analysis, SQL-based data management, statistical analysis, and dashboard development. The findings describe historical associations and should not be interpreted as proof of causation or as a complete loan-approval model.
